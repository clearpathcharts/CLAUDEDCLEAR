────────────────────────────────────────

2. Unzip if needed:

3. Redeploy the console:
     bash ~/clearpath-money-channels/RUN-REDEPLOY.sh
4. Read the money-channel checklist:

5. Fastest money path = YouTube:
     cd ~/clearpath-money-channels/env-templates
     nano youtube.env          # paste your 3 Google OAuth values

     bash ../scripts/SET-META.sh
7. TikTok:
     nano tiktok.env
     set -a; source tiktok.env; set +a
